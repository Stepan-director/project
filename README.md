#  Прогнозирование прочностных характеристик доменного кокса

Система прогнозирует прочность кокса (М10, М40) по гранулометрическому составу и данным с камер конвейера. 
Решение закрывает разрыв между отбором пробы и получением результатов лабораторного анализа — 
технолог получает ответ за минуты, а не часы.

---

##  Бизнес-ценность
Бизнес-цель
Цель системы — сделать процесс выплавки чугуна управляемым и предсказуемым. Мы перестаём реагировать на проблемы постфактум и начинаем предотвращать их до того, как уголь попадёт в печь.


### Проблема

Сегодня на заводе есть разрыв между отбором пробы кокса и получением данных о его прочности. 
Лабораторный анализ занимает 2–4 часа. За это время печь продолжает работать, и если кокс плохой — 
мы уже получили некачественный чугун, который нельзя переплавить.

**Потребность:** закрыть этот разрыв, дать технологу ответ за минуты.

### Допущения (консервативные)

| Допущение | Значение | Обоснование |
|---|---|---|
| Доля кокса, не соответствующего ГОСТу | 4% | По содержанию мелочи (граница ГОСТа) |
| Снижение риска брака чугуна | 1,5% | Экспертная оценка, консервативно |
| Эффективность отсева (при точности модели 70%) | 70% | Precision/recall модели |
| Экономия кокса за счёт отсева | 1,5% | Половина от доли несоответствия |
| Надбавка за марочность | не учитывается в базовом | Потенциальная выручка, а не прямая экономия |

## Архитектура

![Архитектура]()

Система построена на микросервисной архитектуре:

- **# микросервисов** (7 в бизнес-контуре, # в контуре управления)
- **Kafka** для асинхронного обмена данными
- **Kubernetes** для оркестрации и отказоустойчивости
- **Два контура:** бизнес-контур и контур управления (DevOps)
- **Файловый-видеопоток:** для получения и отправки кадров нейросети
